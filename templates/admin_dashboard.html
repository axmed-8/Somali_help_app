Help & Support

{% if is_super_admin %}Super Admin guidance{% else %}Admin operations guide{% endif %}

    {% if is_super_admin %}
  • You have full system access: Admin accounts, backup, audit logs, maintenance, and platform settings.
  • Use + Create staff to add Admin, Hospital, Police, or Fire. Use + Add user for citizens.
  • Use Backup & Restore before major configuration changes.
    • {% else %}
  • Your role is Admin (limited). You can manage citizens, hospitals, police, fire, call center, emergencies, reports, and operational settings.
  • Admin accounts, backup, audit logs, and system kill-switches are Super Admin only and are hidden from this interface.
    • {% endif %}
  • Use My Profile to update your name, email, phone, photo, password, and notification preferences. You can only edit your own account there.
  • Use Emergency Management to assign units and update status.
  • Use AI Intelligence for recommendation metrics — operators still approve dispatch.
  • Hotline and Call Center phones are managed under Call Center settings.
